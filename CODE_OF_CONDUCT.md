# Code of Conduct

## 🤝 Our Commitment

We want GridCraft to be a welcoming, respectful, and collaborative space for everyone.

By participating in this project, you agree to:
- Be respectful and constructive
- Give feedback professionally
- Help create a positive environment
- Focus on improving the project, not attacking people

---

## ✅ Expected Behavior

Examples of good behavior include:

- Using welcoming and inclusive language
- Respecting different opinions and experiences
- Giving constructive feedback
- Helping others learn and grow
- Being patient with beginners
- Taking responsibility for mistakes

---

## ❌ Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or personal attacks
- Toxic, insulting, or discriminatory language
- Trolling or intentionally disruptive behavior
- Spam or irrelevant self-promotion
- Sharing private information without permission
- Any behavior that makes others feel unsafe or unwelcome

---

## 🛠 Contribution Standards

When contributing:

- Keep pull requests focused and clean
- Write understandable code
- Test your changes when possible
- Respect project architecture and conventions
- Discuss major changes before implementing them

---

## 🚨 Reporting Issues

If someone violates this Code of Conduct, report it to the maintainers privately.

Please include:
- What happened
- Relevant screenshots/logs if available
- Any context that helps explain the situation

All reports will be reviewed fairly and respectfully.

---

## ⚖ Enforcement

Project maintainers may:
- Warn contributors
- Remove comments or content
- Reject contributions
- Temporarily or permanently ban users for severe misconduct

Actions will depend on the severity and frequency of violations.

---

## ❤️ Final Note

GridCraft is built by people who enjoy creating cool things together.

Be kind. Be respectful. Ship awesome stuff 🚀
